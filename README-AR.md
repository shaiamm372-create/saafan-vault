# كفو · خزنة سعفان

منصة عربية لأمن الذكاء الاصطناعي، يقدّمها نادي الأمن السيبراني في جامعة الملك فيصل.
حاول تخدع سعفان وتفتح خزنته: 16 مهمة في **خزنة النماذج**، و30 مهمة في **مختبر الوكلاء**، و6 دروس، و3 مختبرات دفاع موجّهة.

مبنية على المشروع مفتوح المصدر [Prompt Injection CTF](https://github.com/ppradyoth/prompt-injection-ctf) من تطوير Pradyoth Prashanth، وتُنشر بترخيص MIT (انظر ملف `LICENSE`، ويجب إبقاؤه).

## وش اللي تغيّر عن الأصل

- الواجهة كاملة بالعربي ومن اليمين لليسار، بخط IBM Plex Sans Arabic وخط Reem Kufi مضمّنين في المشروع (`public/fonts`).
- الألوان أحسائية: ذهبي الخلاص، وأخضر السعف، وبنّي خشب النخل (في `src/app/globals.css`).
- نصوص المهام والدروس والمختبرات بالعربي. أما **نص الهجوم وردود النماذج والتقييم فبقيت بالإنجليزي** مثل الأصل.
- أُزيل المسار `/ctf` والتحويلات إلى موقع المؤلف الأصلي، فيشتغل الموقع من جذر الرابط مباشرة.
- حُدّث Next.js إلى 16.4.5 لسد ثغرة أمنية حرجة في الإصدار السابق.

## أين أعدّل الأسماء؟

كل الأسماء في ملف واحد: `src/lib/brand.ts` (اسم المنصة، واسم الحارس، واسم النادي، والبريد).

| الملف | المحتوى |
| --- | --- |
| `src/lib/i18n/challenges-ar.ts` | نصوص المهام الـ16 |
| `src/lib/i18n/agentic-ar.ts` | نصوص مهام الوكلاء الـ30 ورسائل السجلات |
| `src/lib/i18n/ar.ts` | أنواع الهجمات، والصعوبات، والرتب، والشارات |
| `src/lib/i18n/grader-ar.ts` | رسائل المقيّم والأخطاء |
| `src/lib/learning.ts` | الدروس الستة |
| `src/lib/guided-labs.ts` | المختبرات الموجّهة |

## النشر على Vercel

1. ارفعي المشروع إلى مستودع في حسابك على GitHub.
2. ادخلي [vercel.com](https://vercel.com) وسجّلي الدخول بحساب GitHub.
3. اضغطي **Add New… ← Project**، واختاري المستودع، ثم **Import**.
4. اتركي الإعدادات الافتراضية كما هي (Vercel يتعرّف على Next.js تلقائيًا)، واضغطي **Deploy**.
5. بعد دقيقتين تقريبًا يطلع لك رابط مثل `https://اسم-المشروع.vercel.app`.

اللعبة تشتغل كاملة بدون أي إعداد إضافي: التقييم الافتراضي يعمل بدون مفاتيح.

### إعدادات اختيارية (Settings ← Environment Variables)

| المتغير | فائدته |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | الرابط النهائي لو ربطتي نطاقًا خاصًا (مثل `https://ctf.example.com`) |
| `OPENAI_API_KEY` أو `ANTHROPIC_API_KEY` | تشغيل نموذج حقيقي على الخادم بدل المقيّم الافتراضي (عليه تكلفة) |
| `FIREBASE_PROJECT_ID`، `FIREBASE_CLIENT_EMAIL`، `FIREBASE_PRIVATE_KEY` | حفظ لوحة المتصدرين والمجتمع |
| `NEXT_PUBLIC_FIREBASE_*` | تسجيل الدخول بـ Google |

بدون Firebase: اللعبة والمهام والدروس كلها تشتغل، لكن لوحة المتصدرين والمجتمع وتسجيل الدخول ما تحفظ شيئًا. القيم المطلوبة موضّحة في `.env.local.example`.
