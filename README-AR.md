# منصة تحديات أمن الذكاء الاصطناعي · نادي الأمن السيبراني

منصة تحديات في أمن الذكاء الاصطناعي، يقدّمها نادي الأمن السيبراني في جامعة الملك فيصل: 16 مهمة على النماذج اللغوية، و30 مهمة على الوكلاء، و6 دروس، و3 مختبرات دفاع موجّهة.

تُنشر بترخيص MIT. **لا تحذفي ملف `LICENSE`** من المستودع، فبقاؤه مع الشفرة هو شرط الترخيص.

## اللغة

- الواجهة كاملة بالإنجليزي.
- **هدف المهمة والتلميحات بالعربي** في المهام الـ16 ومهام الوكلاء الـ30.
- نص الهجوم وردود النماذج والتقييم بالإنجليزي.

## الهوية

- شعار النادي في `public/brand` (نسخة الشعار الكامل، ونسخة الدرع فقط).
- ألوان الشعار (التركوازي والذهبي) معرّفة في `src/app/globals.css`.

## أين أعدّل الأسماء؟

كل الأسماء في ملف واحد: `src/lib/brand.ts` (اسم النادي، واسم المنصة، والبريد، ومسار الشعار).

| الملف | المحتوى |
| --- | --- |
| `src/lib/i18n/challenges-ar.ts` | الهدف والتلميحات بالعربي للمهام الـ16 |
| `src/lib/i18n/agentic-ar.ts` | الهدف والتلميحات بالعربي لمهام الوكلاء الـ30 |

## النشر على Vercel

1. ارفعي المشروع إلى مستودع في حسابك على GitHub.
2. ادخلي [vercel.com](https://vercel.com) وسجّلي الدخول بحساب GitHub.
3. اضغطي **Add New… ← Project**، واختاري المستودع، ثم **Import**.
4. اتركي الإعدادات الافتراضية كما هي (Vercel يتعرّف على Next.js تلقائيًا)، واضغطي **Deploy**.
5. بعد دقيقتين تقريبًا يطلع لك رابط مثل `https://اسم-المشروع.vercel.app`.

اللعبة تشتغل كاملة بدون أي إعداد إضافي: التقييم الافتراضي يعمل بدون مفاتيح.

### إعدادات اختيارية (Settings ← Environment Variables)

| المتغير | فائدته |
| --- | --- |
| `NEXT_PUBLIC_SITE_URL` | الرابط النهائي لو ربطتي نطاقًا خاصًا (مثل `https://ctf.example.com`) |
| `OPENAI_API_KEY` أو `ANTHROPIC_API_KEY` | تشغيل نموذج حقيقي على الخادم بدل المقيّم الافتراضي (عليه تكلفة) |
| `FIREBASE_PROJECT_ID`، `FIREBASE_CLIENT_EMAIL`، `FIREBASE_PRIVATE_KEY` | حفظ لوحة المتصدرين والمجتمع |
| `NEXT_PUBLIC_FIREBASE_*` | تسجيل الدخول بـ Google |

بدون Firebase: اللعبة والمهام والدروس كلها تشتغل، لكن لوحة المتصدرين والمجتمع وتسجيل الدخول ما تحفظ شيئًا. القيم المطلوبة موضّحة في `.env.local.example`.

## التشغيل على جهازك

```bash
npm install
npm run dev     # http://localhost:3000
npm test        # 460 اختبار
npm run build
```

يحتاج Node.js 22 أو أحدث.
